# kylelieber.com

Personal website and engineering portfolio of Kyle Lieber, Staff Technical Lead.

[![Netlify Status](https://api.netlify.com/api/v1/badges/69a9ea9c-27aa-498a-b201-900a121e07c2/deploy-status)](https://app.netlify.com/sites/kylelieber/deploys)

## Tech Stack
* **Framework**: [Astro](https://astro.build/)
* **Styling**: Pure CSS with responsive design system & dark/light theme switching
* **Hosting**: [Netlify](https://www.netlify.com/)
* **Node**: 22.x

## Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
# or ./serve

# Build for production
npm run build
# or ./build
```
